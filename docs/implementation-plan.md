# План реализации

Основание: ТЗ «Объекты и задачи» и согласованный план в чате.

1. React/TypeScript/Vite, Material UI, Router, TanStack Query, Supabase.
2. Миграции: profiles, projects, tasks, неизменяемая история; RLS и закрытая запись через RPC.
3. Переходы: new → in_progress → review → accepted; review → rework (комментарий); rework → in_progress.
4. Вход, объекты, карточки, мои задачи, формы постановщика и кнопки исполнителя.
5. Изоляция ролей, переходы, история, гонки, переназначение и удаление: SQL, API, браузерные проверки.
6. Vercel/GitHub, демонстрационные данные, README, объяснение и черновик сдачи.

Решения: мягкое удаление объекта вместе с задачами; переназначение в любом статусе без изменения статуса; описание необязательно. Автор и время задаются базой. Регистрация выключена. Роли выдаёт администратор.

Ожидаемый результат: опубликованное приложение, миграции и исходники, 1 постановщик и 2 исполнителя, 3 объекта и 5 статусов, материалы для сдачи. Для публикации нужны доступы к Supabase и хостингу; пароли не включаются в Git.
